## 🖥️ Server Owner Checklist

- Back up worlds, players, quests, configs, and server files.
- Check the matching server pack.
- Confirm Java, Minecraft, and NeoForge versions.
- Test the update on a copied world first.
- Keep a rollback plan ready.
