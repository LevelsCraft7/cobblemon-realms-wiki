# 🐞 Report a Bug

{% hint style="info" %}
Found a problem with **Cobblemon Realms** or this wiki? Use one of the official reporting channels below so the issue can be checked and reproduced efficiently.
{% endhint %}

---

## 🧭 Choose the right channel

| Report type | Recommended channel |
| --- | --- |
| Modpack bug, crash, broken feature or server issue | GitHub issue or Discord support feedback |
| Incorrect, missing or outdated wiki information | GitHub issue |
| Quick question or report requiring discussion | Discord support feedback |

---

## 🐛 Report a modpack bug on GitHub

Use the pre-filled form below. Complete every relevant field before submitting the issue.

[**Open a pre-filled modpack bug report →**](https://github.com/LevelsFR/cobblemon-realms-wiki/issues/new?title=%5BModpack+Bug%5D+Brief+description&body=%23%23+Report+type%0AModpack+bug%0A%0A%23%23+Cobblemon+Realms+version%0AExample%3A+6.0.0%0A%0A%23%23+Minecraft+version%0AExample%3A+1.21.1%0A%0A%23%23+Launcher%0ACurseForge+%2F+Prism+Launcher+%2F+Other%0A%0A%23%23+Environment%0ASingle-player+%2F+Dedicated+server%0A%0A%23%23+What+happened%3F%0ADescribe+the+issue+clearly.%0A%0A%23%23+Steps+to+reproduce%0A1.%0A2.%0A3.%0A%0A%23%23+Expected+result%0AWhat+should+have+happened%3F%0A%0A%23%23+Logs+and+screenshots%0AAttach+the+latest+log%2C+crash+report%2C+and+screenshots+when+relevant.%0A)

### Information to include

- The exact **Cobblemon Realms version**
- Your **Minecraft version** and launcher
- Whether the issue occurs in single-player or on a server
- Clear steps that reproduce the problem
- The expected and actual results
- The latest log, crash report and screenshots when relevant

{% hint style="warning" %}
Never publish passwords, private server credentials, access tokens or personal information inside logs or screenshots.
{% endhint %}

## 📚 Report a wiki issue on GitHub

Use this form when a page contains incorrect, missing, outdated or unclear information.

[**Open a pre-filled wiki report →**](https://github.com/LevelsFR/cobblemon-realms-wiki/issues/new?title=%5BWiki%5D+Page+or+documentation+issue&body=%23%23+Page+URL%0APaste+the+affected+wiki+page+URL.%0A%0A%23%23+Language%0AEnglish+%2F+French%0A%0A%23%23+What+is+incorrect+or+missing%3F%0ADescribe+the+documentation+issue.%0A%0A%23%23+Suggested+correction%0AProvide+the+corrected+information+when+possible.%0A%0A%23%23+Screenshots+or+references%0AAdd+anything+that+helps+verify+the+report.%0A)

Please include the affected page URL, its language and the exact section that needs correction.

---

## 💬 Report through Discord

You can also post the report in the official **support feedback** channel:

[**Open the Discord support feedback channel →**](https://discord.com/channels/272468475287437312/1361441643298820126)

Keep one problem per message and include the same technical information requested by the GitHub form.

{% hint style="success" %}
A precise report with reproducible steps is much easier to verify and fix than a message saying only that something does not work.
{% endhint %}
