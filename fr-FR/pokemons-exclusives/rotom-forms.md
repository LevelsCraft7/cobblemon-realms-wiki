# 🔌 Formes Motisma

---

{% hint style="info" %}
## 📘 Mise à jour des apparitions

Cette page a été mise à jour pour le datapack actuel **Cobblemon Realms Biome Expanded Spawns v6.0**.

Motisma n’utilise plus les anciennes règles d’apparition liées aux structures ou à la météo.
Il apparaît désormais dans l’**Overworld**, à proximité de certains blocs électriques ou technologiques de Cobblemon.
{% endhint %}

---

| 🌍 Catégorie | ✅ Règle actuelle |
|---|---|
| Dimension | Overworld |
| Tag de biome | `#cobblemon:is_overworld` |
| Rareté | Rare |
| Niveaux | 20-75 |
| Type de position | Au sol |
| Condition spéciale | Doit apparaître près d’un bloc électrique ou technologique valide |

## 🔄 Changement de forme

- 🎯 Placez-vous près d’un appareil compatible
- 🖱️ Faites un clic droit sur Motisma
- 📟 Ou utilisez un **Moniteur de données**
