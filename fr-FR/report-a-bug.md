# 🐞 Signaler un problème

{% hint style="info" %}
Vous avez trouvé un problème dans **Cobblemon Realms** ou sur ce wiki ? Utilisez l’un des canaux officiels ci-dessous afin que le signalement puisse être vérifié et reproduit efficacement.
{% endhint %}

---

## 🧭 Choisir le bon canal

| Type de signalement | Canal recommandé |
| --- | --- |
| Bug du modpack, crash, fonctionnalité cassée ou problème serveur | Issue GitHub ou salon Discord support feedback |
| Information incorrecte, manquante ou obsolète sur le wiki | Issue GitHub |
| Question rapide ou signalement nécessitant une discussion | Salon Discord support feedback |

---

## 🐛 Signaler un bug du modpack sur GitHub

Utilisez le formulaire prérempli ci-dessous. Complétez tous les champs pertinents avant d’envoyer l’issue.

[**Ouvrir un signalement de bug prérempli →**](https://github.com/LevelsFR/cobblemon-realms-wiki/issues/new?title=%5BBug+Modpack%5D+Description+courte&body=%23%23+Type+de+signalement%0ABug+du+modpack%0A%0A%23%23+Version+de+Cobblemon+Realms%0AExemple+%3A+6.0.0%0A%0A%23%23+Version+de+Minecraft%0AExemple+%3A+1.21.1%0A%0A%23%23+Launcher%0ACurseForge+%2F+Prism+Launcher+%2F+Autre%0A%0A%23%23+Environnement%0ASolo+%2F+Serveur+d%C3%A9di%C3%A9%0A%0A%23%23+Que+s%27est-il+pass%C3%A9+%3F%0AD%C3%A9crivez+clairement+le+probl%C3%A8me.%0A%0A%23%23+%C3%89tapes+pour+reproduire%0A1.%0A2.%0A3.%0A%0A%23%23+R%C3%A9sultat+attendu%0AQue+devait-il+se+passer+%3F%0A%0A%23%23+Logs+et+captures%0AAjoutez+le+latest.log%2C+le+crash-report+et+des+captures+lorsque+cela+est+pertinent.%0A)

### Informations à fournir

- La **version exacte de Cobblemon Realms**
- Votre **version de Minecraft** et votre launcher
- Si le problème apparaît en solo ou sur un serveur
- Des étapes claires permettant de reproduire le problème
- Le résultat attendu et le résultat obtenu
- Le latest log, le crash-report et des captures lorsque cela est pertinent

{% hint style="warning" %}
Ne publiez jamais de mots de passe, d’identifiants privés de serveur, de jetons d’accès ou d’informations personnelles dans vos logs ou captures.
{% endhint %}

## 📚 Signaler un problème du wiki sur GitHub

Utilisez ce formulaire lorsqu’une page contient une information incorrecte, manquante, obsolète ou difficile à comprendre.

[**Ouvrir un signalement wiki prérempli →**](https://github.com/LevelsFR/cobblemon-realms-wiki/issues/new?title=%5BWiki%5D+Erreur+ou+contenu+manquant&body=%23%23+URL+de+la+page%0ACollez+l%27URL+de+la+page+concern%C3%A9e.%0A%0A%23%23+Langue%0AFran%C3%A7ais+%2F+Anglais%0A%0A%23%23+Qu%27est-ce+qui+est+incorrect+ou+manquant+%3F%0AD%C3%A9crivez+le+probl%C3%A8me+de+documentation.%0A%0A%23%23+Correction+sugg%C3%A9r%C3%A9e%0AIndiquez+la+bonne+information+lorsque+cela+est+possible.%0A%0A%23%23+Captures+ou+r%C3%A9f%C3%A9rences%0AAjoutez+tout+%C3%A9l%C3%A9ment+permettant+de+v%C3%A9rifier+le+signalement.%0A)

Indiquez l’URL de la page concernée, sa langue et la section exacte à corriger.

## 💬 Signaler le problème sur Discord

Vous pouvez également publier votre signalement dans le salon officiel **support feedback** :

[**Ouvrir le salon Discord support feedback →**](https://discord.com/channels/272468475287437312/1361441643298820126)

Gardez un seul problème par message et ajoutez les mêmes informations techniques que celles demandées par le formulaire GitHub.

{% hint style="success" %}
Un signalement précis avec des étapes reproductibles est beaucoup plus simple à vérifier et à corriger qu’un message indiquant uniquement que quelque chose ne fonctionne pas.
{% endhint %}
